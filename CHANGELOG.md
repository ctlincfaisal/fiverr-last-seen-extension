# Changelog

## v0.3.0 — Popup and GitHub release polish

- Redesigned the toolbar popup with a dark interface and green accents.
- Added an extension icon inside the popup header.
- Show the exact local date/time in **12-hour AM/PM** format and a separate friendly relative-time label (e.g. **a minute ago**, **3 days ago**).
- Refresh relative-time text while the popup is open without network requests.
- Improved loading, unavailable-data, and retry states.
- Kept standard Chrome action icons for the pinned toolbar icon.
- Expanded the README and added contributing guidelines and release notes.
- The README developer section contains name, skills, and website only; no donation request.

## v0.2.1 — Readable dates and project credits

- Displayed relative timestamps alongside formatted dates.
- Configured icon paths for Chrome toolbar and extension management.
- Added developer contact details.

## v0.2.0 — No-reload capture

- Observed existing page-initiated Fetch/XHR responses.
- Removed debugger-based page reload from popup click.
- Stored captured timestamp in browser tab memory.

All versions are unofficial and experimental; no live compatibility guarantee is implied.
